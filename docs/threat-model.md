# Threat Model (Draft)

> สถานะ: Draft — ค่าเริ่มต้นที่ผู้เขียนเลือกเอง ยังรอการยืนยันจากผู้ใช้ (ดูข้อ 6)

## 1. ขอบเขต
- เป้าหมายแรก: **HTTP API แบบ request/response** ที่อยู่หลัง gateway หนึ่งจุด
- ยังไม่ครอบคลุม: LLM/agent gateway, เครือข่ายภายใน, ระบบปฏิบัติการ

## 2. Asset
- ข้อมูลในฐานข้อมูลและ route ที่ผู้ใช้ไม่ได้รับสิทธิ์
- ความพร้อมใช้งานของบริการ (ป้องกันการถล่มด้วยคำขอจำนวนมาก)

## 3. ผู้โจมตีที่สมมติ
- ผู้ส่งคำขอจากภายนอกที่ทำ SQL injection, XSS, path traversal ได้
- ผู้ส่งที่พยายามหลบ pattern ด้วยการ encode ซ้ำหลายชั้น
- ผู้ส่งที่ยิงคำขอถี่เพื่อเปิดช่อง DoS

## 4. สิ่งที่ไม่ป้องกันในเฟสนี้
- zero-day ใน application เอง
- การโจมตีที่ใช้ payload ที่ไม่อยู่ใน pattern set
- ผู้โจมตีที่ได้ token ที่ถูกต้องแล้ว (authn อยู่นอกขอบเขต)

## 5. วิธีวัดผล
- ยังไม่มี: ต้องเทียบกับ baseline (ModSecurity + OWASP CRS) บนชุดข้อมูลที่มี label

## 6. รอการตัดสินใจ
1. เป้าหมาย: HTTP API (ค่าเริ่มต้นที่ใช้ในเอกสารนี้)
2. Vattapada: ยังไม่ใช้ในเฟสนี้ จนกว่าจะมีการ ablation test
3. ชื่อมรรค 8 / วัตรบท 7: คงไว้เฉพาะในเอกสารและ comment
4. ภาษาประเมินผล: Rust (ค่าเริ่มต้น)
5. ทรัพยากรและ review โดยคนนอก: ยังไม่กำหนด
